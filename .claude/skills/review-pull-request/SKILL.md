# Review Pull Request

> **Writing style:** Follow the writing rules in [AGENT_RULES](../../references/AGENT_RULES.md) for all text you write — chat messages, questions, plans, reports, and generated docs.

Writes a structured code review. It fetches a PR's description and diff with **MCP**. If no MCP is available, it uses the platform **CLI** (`gh`, `glab`, or a Bitbucket CLI). If there is no working CLI either, it uses **Claude browser control** (e.g. Claude in Chrome) on the platform website.

## How to Use This Skill

1. Find the access method (MCP, CLI, or browser), then the target PR and its diff.
2. Check that the code matches the requirements before you run the sub-skill checks.
3. Load the needed sub-skills in full and use them on the diff.
4. Write the review report. Then, if the user wants, post it as **file + line** comments with MCP, CLI, or browser.

## Notes

- Never show secrets, credentials, or internal environment values from the diff in the review report. Replace them with `[REDACTED]` and report the finding.
- If the PR description is empty or very short, note this in the Summary as a process issue.
- This skill is read-only by default. It does not change any files unless the user clearly asks for auto-fixes.
- Never add AI/agent attribution to posted comments (no "Generated by", "Reviewed by Claude", "Co-Authored-By: Claude", or similar signature lines). Each comment has only the finding.
