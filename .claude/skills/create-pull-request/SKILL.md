# Create Pull Request

> **Writing style:** Follow the writing rules in [AGENT_RULES](../../references/AGENT_RULES.md) for all text you write — chat messages, questions, plans, reports, and generated docs.

Writes a fully filled pull request / merge request description. It finds the platform template, then fills it using git changes, tickets, plans, and user input. The agent can create the PR directly with a platform MCP. If no MCP is available, it uses the platform CLI (`gh`, `glab`, or a Bitbucket CLI). If there is no working CLI either, it uses Claude browser control (e.g. Claude in Chrome) to fill and submit the form on the platform website.

## When to Use

- Developer wants to open a PR/MR and needs a description
- Filling a PR template from a git diff, ticket, or design doc
- Creating a PR with a GitHub / GitLab / Bitbucket MCP, with the `gh` / `glab` / Bitbucket CLI, or in the browser with Claude browser control

## Notes

- The user **must** commit their changes before using this skill, because it uses `git diff` to collect context.
- Always use the target branch chosen by the user in **Step 3** as the base branch for the diff and PR.
- If the git diff is very large (>300 lines), sum it up by file/module instead of listing every line.
- Never include secrets, credentials, or internal environment values in the PR description.
- Never add AI/agent attribution to the PR title or description (no "Generated by", "Created by Claude", "Co-Authored-By: Claude", or similar signature lines).
