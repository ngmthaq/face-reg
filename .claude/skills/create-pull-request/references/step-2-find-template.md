# Step 2 — Find the PR Template

Look for a template in these places:

| Platform      | Template location                                                        |
| ------------- | ------------------------------------------------------------------------ |
| **GitHub**    | `.github/pull_request_template.md`, `.github/PULL_REQUEST_TEMPLATE/*.md` |
| **GitLab**    | `.gitlab/merge_request_templates/*.md`                                   |
| **Bitbucket** | `.bitbucket/pull_request_template.md`                                    |

**Rules:**

- **One** template found → use it.
- **More than one** found → ask the user which one to use.
- **None** found → use the default: [pull-request-template.md](./pull-request-template.md).
