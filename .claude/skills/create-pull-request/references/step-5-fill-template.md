# Step 5 — Fill the Template

Fill every section of the template:

- **Description**: Say _what_ changed and _why_. Use plain words.
- **Type of Change**: Check the boxes that fit.
- **Changes Made**: List the real changes from the git diff or plan.
- **How to Test**: Write clear steps for the reviewer.
- **Checklist**: Check only what you know is done. Leave the rest for the developer.
- **Related Issues**: Add ticket or issue links (e.g. `Closes #123`).
- **Screenshots**: Say "Not needed", or ask the user to add them.

If you have enough context, do **not** leave a section empty.

Do **not** add AI attribution. No "Generated by", "Created by Claude", "Co-Authored-By: Claude", or similar lines. The description must read as the developer's own.
