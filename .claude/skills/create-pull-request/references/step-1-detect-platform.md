# Step 1 — Find the Platform

Run this command to get the remote URL:

```bash
git remote get-url origin
```

Use the URL to find the platform:

| URL has                         | Platform                         |
| ------------------------------- | -------------------------------- |
| `github.com`                    | GitHub                           |
| `gitlab.com` or your own GitLab | GitLab                           |
| `bitbucket.org`                 | Bitbucket                        |
| Anything else                   | Other (use the default template) |
