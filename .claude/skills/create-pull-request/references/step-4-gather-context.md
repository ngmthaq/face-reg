# Step 4 — Collect Context

Collect everything that helps you fill the template:

| Source                | How to get it                                                                    |
| --------------------- | -------------------------------------------------------------------------------- |
| **Git changes**       | `git diff <target-branch>...HEAD` and `git log <target-branch>...HEAD --oneline` |
| **User input**        | What the user gave when starting this skill (ticket URL, requirement, plan link) |
| **Plan / design doc** | Read any linked `.md` plan files in the project                                  |
| **Ticket**            | If the user gave a URL, read the ticket                                          |
